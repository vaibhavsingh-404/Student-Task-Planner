STUDENT TASK PLANNER

Problem statement:
Students often manage assignments, revision, and deadlines in different places.
This can make it difficult to remember pending work and track progress.

Solution:
A simple browser-based task planner that keeps student tasks together.

Features:
- Add a task with an optional due date and priority.
- Mark tasks as completed.
- Delete tasks.
- Filter all, pending, and completed tasks.
- View task totals and overall completion progress.
- Save tasks in browser localStorage, so they remain after refreshing the page.

How to run:
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js in the same folder.
3. Open index.html in any modern web browser.
4. No installation or internet connection is required.

Files:
- index.html: website structure
- style.css: layout and styling
- script.js: task planner functionality
